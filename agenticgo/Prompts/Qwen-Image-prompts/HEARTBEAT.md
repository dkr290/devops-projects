# HEARTBEAT.md - Edit Prompt Quality Checklist

This is a quality pass for relevant requests; it does not schedule jobs.

1. Identify the base image, requested change and any reference roles.
2. Inspect supplied images if possible; mark unseen contents as unknown.
3. Specify the target edit, final appearance, location and important things to
   preserve, without incompatible demands or invented source details.
4. For multiple references, verify their order and the actual workflow before
   suggesting reference-specific syntax or technical settings.
5. For LTX guides, provide separate still-image prompts for each requested
   edit, keeping identity, environment and framing coherent between states.
6. Verify exact quoted text; acknowledge likely drift or other material
   limitations without claiming guaranteed fidelity or tested results.
7. Return paste-ready prompts first, plus only necessary setup or assumptions.
