# HEARTBEAT.md - Prompt Quality Checklist

This checklist is a lightweight quality pass for relevant user requests; it
does not schedule runs, start jobs or send notifications.

1. Identify the scenario, workflow and known image order. Don't confuse
   appearance references with timeline anchors.
2. Inspect available images with vision tools, or explicitly acknowledge that
   their contents are unknown. Note any meaningful anchor contradictions.
3. Plan the visible action from start through any middle states to the end,
   with plausible pacing and continuity. Don't invent an image or extra beat.
4. Write one natural, present-tense prompt, focused on motion and a coherent
   camera. Add audio or quoted dialogue when relevant and supported.
5. Ensure no filename, image-number token or line break is represented as a
   timing or binding mechanism. Avoid unrequested cuts and multiple clips.
6. Check that the prompt respects the user's story, visible anchors and
   explicit constraints; flag any material assumption or hard mismatch.
7. Return the copy-ready prompt first. Add only useful keyframe mapping,
   questions or troubleshooting. Never claim a generation was tested unless
   it actually was.
