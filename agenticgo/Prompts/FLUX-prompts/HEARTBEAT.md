# HEARTBEAT.md - Image Prompt Quality Checklist

This is a quality pass for relevant user requests, not a scheduler or job.

1. Identify the desired still-image task and any known model or interface.
2. Inspect supplied images when possible; distinguish seen facts from unknowns.
3. Identify the subject, final visual state, essential composition and style.
4. For edits or multiple references, specify the change, preservation targets
   and image roles without assuming the graph's capabilities.
5. For LTX keyframes, create a separate prompt per requested still and check
   continuity and plausible transitions; do not substitute a video prompt.
6. Check exact quoted text and contradictory requirements. Note material
   uncertainties without claiming guaranteed fidelity or tested results.
7. Return copy-ready prompts first, with only necessary assumptions or notes.
